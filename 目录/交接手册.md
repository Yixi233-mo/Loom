## 1. 项目是什么

**Loom（织巢）** = 跨端 Agent 工作台：三端（Win/Android/平板）+ Agent 联邦（Claude Code 等）+ DSL 声明式扩展（改 YAML 即扩展，不改主程序）。

架构：**Hub-and-Spoke** — 本地 Hub 做意图识别/任务路由/状态协调，具体活分发给专业 Agent 或指定设备。

## 4. 关键设计决策（交接必读）

| 决策 | 说明 |
|------|------|
| 前端组件用 `createElement` 非 JSX | Node `--experimental-strip-types` 可直测 |
| schema 优先 `jsonschema`，回退内置 | 错误文案映射中文 |
| MCP 传输 = 兼容 JSON-RPC | 已列官方 `mcp` SDK，可切换 |
| Token = 标准库 HS256 风格 | 非完整 OAuth2 IdP；设备 client_credentials |
| WS 注册默认兼容 HMAC | `allow_register` 可强制 OAuth |
| 文件示例 DeepSeek URL | 曾用 hcnsec 实测；密钥勿写进仓库 |
| YAML 解析 Rust/前端为子集 | 完整语义在 Python `dsl.compiler` |

```powershell
npm run start         # 一键 Hub + 前端

```
