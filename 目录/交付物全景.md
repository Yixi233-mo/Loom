# 交付物全景（终版形态）

> 回答：**是的，最终就按下表交付。** 与工程现状对齐如下。

| 交付物 | 形态 | 给谁 | 安装方式 | 现状 |
|--------|------|------|----------|------|
| Hub | Docker 镜像 / 单文件可执行 | 部署者（你/团队管理员） | `docker run` 一条命令 | Docker ✅ · exe 可选后续 |
| Shell · Windows | `.msi` 安装包 | 每个用户 | 双击安装 | 壳可 `cargo run` · **msi 待打包** |
| Shell · Android | `.apk` 安装包 | 每个用户 | 侧载 / 应用商店 | UI 已适配 · **打包链待配** |
| DSL 模板 | `.yaml` 文件包 | 每个用户 | 放进 `plugins/` | 示例包 ✅ 热加载 ✅ |
| 配置 | `.env` / `config.yaml` | 部署者 | 手动填写 | 变量已约定 ✅ |

## 配套

- 手机可试总览：仓库根目录 **`交付台.html`**（单文件，可进手机模拟器）
- 详细勾选：`目录/FE7_交付清单.md`
- 三端人工步骤：`目录/FE5_三端验证步骤.md`

## 终版安装一句话

1. 部署者：`docker compose up hub`（填好 `.env`）
2. 用户 Windows：双击 `Loom-Setup.msi`
3. 用户 Android：安装 `Loom.apk`
4. 扩展：把 YAML 包扔进 `plugins/`
