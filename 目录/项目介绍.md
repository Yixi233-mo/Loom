# Loom · 织巢 — 项目介绍

> 跨端协作、Agent 联邦、DSL 驱动的工作台  
> 把 Windows / Android / 平板编织成一台电脑，把手边的 AI Agent 编织成一个团队。

---

## 一句话定位

**可生长的跨端 Agent 工作台**：三端自动协调，Agent 可插拔（Claude Code 等），用 YAML DSL 声明一切功能——改声明即扩展，不改主程序。

---

## 核心功能

### 1. 对话与任务
- **对话区**：与 AI 聊天；固定滑窗 / 放大；支持自定义 LLM 模型对话
- **任务面板**：任务状态、结果卡片（含 tokens / latency / 降级档位）
- **文件区**：上传 / 列表 / 删除（Hub 集中存储）

### 2. 自定义 LLM
- 配置 OpenAI 兼容 API（Base URL + Key，**Key 加密存储**）
- 按 URL+Key **真实拉取**服务商模型列表（支持 `/v1/models`、`/v1beta/models`）
- 选择模型 + **测试对话** 一键验证

### 3. MCP 外接服务
- 填 MCP 地址 → **检测连接** → 显示服务名与工具列表
- 内置演示 MCP（`npm run mcp:demo`），无需 Claude Code 也能自测

### 4. DSL 驱动扩展
- **四类 DSL**：Workflow / Plugin / Agent / Trigger
- **DSL 编辑器**：文件 / 表单双模式，保存前 Schema 校验
- **热加载**：保存 YAML 2s 内生效，Hub 不重启
- **对话式生成**：说需求 → 生成 DSL → diff 确认才落盘

### 5. 跨端协同
- 手机触发 → Hub 路由 → PC 执行 → 平板/手机查看
- 设备离线排队、上线自动分发；结果实时广播

### 6. 可观测与安全
- 结构化日志（trace_id 全链路）
- 降级链：Cloud API → Ollama → 规则兜底
- Token 熔断（单任务 10000）
- OAuth token 鉴权（签发 / 续期 / 吊销）

## 技术栈

| 层 | 技术 |
|----|------|
| Shell | Tauri 2.0 + React 19 + TypeScript + Vite |
| Hub | Python 3.11+ + FastAPI + Uvicorn + LangGraph + Pydantic |
| DSL | YAML + PyYAML + JSON Schema + jsonschema |
| Agent | MCP（兼容 JSON-RPC）+ httpx |
| Device | WebSocket + HMAC-SHA256 |
| Store | SQLite |
| Deploy | Docker + GitHub Actions / Releases |

## 使用说明

### 启动

```powershell
# 1) 后端 Hub（REST + WebSocket）
npm run start:hub

# 2) 前端（另开终端）
npm run dev
# 浏览器打开 http://localhost:5173/

# 或一键同时启动
npm run start
```

**单文件预览**（无需起服务，Hub 功能除外）：

```powershell
npm run build:single
# 打开 app.html
```

### 配置自定义 LLM

1. 页面「自定义 LLM」填名称、`https://api.deepseek.com/v1`、API Key → **保存配置**
2. 点 **拉取模型**（自动试 `/v1/models`、`/v1beta/models`）
3. 选模型 → **测试对话** → 到对话区聊天

### 检测 MCP

1. `npm run mcp:demo`（或填真实 Claude Code 地址）
2. 「MCP 外接服务」填 `http://127.0.0.1:3900/mcp` → **检测连接**
3. 看到「✓ 连接成功」和工具列表即通

### 示例插件 / 工作流

- `plugins/example/` — notes 插件 + daily_report / 飞书 / 文件 / 跨端 PDF 四场景
- DSL 改完保存即热加载

### 测试与 CI

```powershell
npm run test   # Python 296 + JS 全绿 + Rust 11
npm run lint
```

推 GitHub 后 `.github/workflows/ci.yml` 自动跑；打 tag 触发 Release（含 `app.html`）。
