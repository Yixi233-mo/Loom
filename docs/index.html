Windows / 平板 / 手机自动协调，内置 Agent 联邦（Claude Code · MCP）， 用 YAML DSL 声明功能——改声明即扩展，尽量不改主程序。

Hub-and-Spoke

本地 Hub 做意图识别与任务路由，具体活分发给专业 Agent 或指定设备。

DSL 驱动

Workflow / Plugin / Agent / Trigger 四类 YAML，校验后保存，约 2 秒热生效。

跨端协同

手机触发 → Hub 路由 → PC 执行 → 多端查看；离线排队，上线自动分发。

可观测 / 安全

trace_id 全链路、降级链、Token 熔断、OAuth 风格鉴权（初版）。
