Loom · 织巢

把 Windows / 平板 / 手机编织成一台电脑，把 Claude Code、Work Buddy 等 AI 编织成一个团队。用 YAML DSL 声明扩展——改声明即扩展。

链路：对话 → 意图识别 → 选端/设备 → 工具 / 外部 Agent / 知识库 RAG → 任务结果多端同步。

Windows 安装使用

1. 双击 dist-bundle/Loom Shell_0.1.0_x64_en-US.msi 2. 启动 Hub： docker compose up -d # 或开发：npm run start 3. 打开 Loom，左侧导航操作

知识库最快上手

知识库 → 新建库 → 导入本地文件（自动识别类型） → 对话问「查资料，xxx」 → 看引用来源

外部源可粘贴链接（Notion/文档站/向量库自动识别），支持路径批量导入。

自定义模型

设置 · 跨端 → 自定义 LLM → Base URL + API Key（加密） → 拉取模型 → 选模型 → 测试对话
