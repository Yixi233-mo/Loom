红线

明确不做什么

避免与大厂正面竞争。只把已有 AI 聚合起来，编排好，用得舒服。

不造大模型没必要拼百亿投入
不造专业 AgentClaude / Operit 已经很好
不造垂直应用不做笔记 / IDE / IM
不做 SaaS本地优先，不碰数据
不做多租户个人 / 小团队，轻量
「大厂做更好的 AI，Loom 做更好的 用 AI 的方式。」 开放性 · 本地优先 · 用户的自动化资产——Workflow 越多，越离不开。

为什么不是又一个 Agent？

因为痛点不在「AI 不够强」，而在入口碎、数据散、生态绑、用法难、不放心。Loom 把选择权还给用户。

用户记住了什么？

不是模型名字，而是「我的 AI 都在 Loom 里」。定义 20 个任务之后，迁移成本就是护城河。

Loom · 织巢 — 大厂做能力，Loom 做体验。大厂做 Agent，Loom 做 Agent 的家。
